# Получить живые данные ядра (для LIVE-режима)

Нужно снять **одно** сообщение из офисного WebSocket и прислать его в чат.
Выберите любой способ.

## Способ 1 — двойной клик (Windows, без редактирования кода)

1. Установите Node.js (один раз): https://nodejs.org → кнопка **LTS**.
2. Откройте папку `tools` и запустите **`ПОЛУЧИТЬ-ДАННЫЕ.bat`** двойным кликом.
3. Когда спросит — вставьте ваш **office-ключ (X-Office-Key)** и нажмите Enter.
   (это тот же ключ, что вводится в приложении в ⚙ Настройках).
4. Скопируйте JSON между метками `=====` и вставьте его в чат.

## Способ 2 — одной командой (любая ОС)

В терминале, в папке `tools`:

```bash
npm install ws
OFFICE_KEY=ВАШ_КЛЮЧ node get-core-data.js        # macOS/Linux
```
Windows PowerShell:
```powershell
npm install ws
$env:OFFICE_KEY="ВАШ_КЛЮЧ"; node get-core-data.js
```

## Способ 3 — попросить Claude в другом чате (на вашем ПК)

Если у вас есть чат с Claude, запущенный на вашем компьютере (он уже умеет
подключаться к ядру) — просто попросите его снять сообщение и покажите вам.
Готовый текст для вставки есть в основном чате.

---

Ключи присылать не нужно — только сам JSON. Он нужен один раз, чтобы настроить
соответствие полей ядра панелям и человечкам (`mapBackendToWorld()` в
`renderer/agents.js`).
